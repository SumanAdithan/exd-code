---
title: Interruption
description: Handling connection drops and user-initiated interruption during AI chat streaming
---

To handle connection drops and user-initiated stream cancellations, interruption mechanisms are integrated into both the client-side chat hook and the server-side response stream.

The following git differences detail the changes made to intercept abort signals, display the option to interrupt during streaming, listen for the escape key to abort streaming, persist partially generated messages to the database under an interrupted status, and capture partial responses in the UI history state:
