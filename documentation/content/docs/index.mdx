# EXD CODE

Welcome to the EXD CODE documentation.

## Tech Stack

EXD CODE is built as a monorepo with four main packages:

- **Terminal UI**: Built with OpenTui
- **Backend Server**: Built with Hono
- **Shared**: Shared types and schemas package
- **Database Layer**: Prisma
