Before integrating Sentry, diagnosing errors in production can be extremely difficult.

### WITHOUT Sentry

<div align="center">
```mermaid
flowchart TD
    subgraph WS [" "]
        direction TB
        
        subgraph TopRow [" "]
            direction LR
            User["User"] --> Server["Hono Server"]
            Server ~~~ Boom["BOOM"]
        end
        
        Err["500 error"]
        
        Boom --> Err
    end
    
    style WS fill:#FFE4E6,stroke:#FDA4AF,color:#E11D48,stroke-width:2px
    style User fill:#BFDBFE,stroke:#60A5FA,color:#1D4ED8,stroke-width:2px,rx:10,ry:10
    style Server fill:#FEF08A,stroke:#FBBF24,color:#B45309,stroke-width:2px,rx:10,ry:10
    style Err fill:#FECACA,stroke:#F87171,color:#991B1B,stroke-width:2px,rx:10,ry:10
    style Boom fill:none,stroke:none,color:#DC2626,font-weight:bold,font-size:20px
    style TopRow fill:none,stroke:none
```
</div>

**You have:**
- no idea which route failed
- no stack trace
- no request context
- no idea how often it happens

<span style={{ color: '#DC2626' }}>*just an angry user on Twitter.*</span>

---

### WITH Sentry

But once you integrate Sentry into your Hono server, the picture changes entirely:

<div align="center">
```mermaid
flowchart TD
    subgraph WS [" "]
        direction TB
        
        subgraph TopRow [" "]
            direction LR
            User["User"] --> Server["Server"]
            Server --> Sentry["Sentry"]
        end
    end
    
    style WS fill:#ECFCCB,stroke:#84CC16,color:#15803D,stroke-width:2px
    style User fill:#BFDBFE,stroke:#60A5FA,color:#1D4ED8,stroke-width:2px,rx:10,ry:10
    style Server fill:#FEF08A,stroke:#FBBF24,color:#B45309,stroke-width:2px,rx:10,ry:10
    style Sentry fill:#E9D5FF,stroke:#C084FC,color:#6B21A8,stroke-width:2px,rx:10,ry:10
    style TopRow fill:none,stroke:none
```
</div>

**With Sentry you get:**
- **Issue**: 'My first Sentry error!' + full stack trace
- **Trace**: POST /sessions 487ms status 500
- **Logs**: filterable by method, path, status, duration
- **Frequency**: 47 events, 12 users affected

<span style={{ color: '#166534' }}>*You know exactly what broke, where, and how often.*</span>

---

### How it works
*Sentry is the FIRST middleware in the Hono request flow*

<div align="center">
```mermaid
flowchart LR
    Req["Request"]
    Sentry["sentry()"]
    Timer["request timer"]
    Route["your route handler"]
    Error["app.onError()"]
    Res["Response"]
    
    Req --> Sentry
    Sentry --> Timer
    Timer --> Route
    Route --> Error
    Error --> Res
    
    Error -. "thrown error caught here" .-> Sentry
    
    style Req fill:#BFDBFE,stroke:#60A5FA,color:#1D4ED8,stroke-width:2px,rx:10,ry:10
    style Sentry fill:#E9D5FF,stroke:#C084FC,color:#6B21A8,stroke-width:2px,rx:10,ry:10
    style Timer fill:#FEF08A,stroke:#FBBF24,color:#B45309,stroke-width:2px,rx:10,ry:10
    style Route fill:#BBF7D0,stroke:#22C55E,color:#14532D,stroke-width:2px,rx:10,ry:10
    style Error fill:#FFEDD5,stroke:#FDBA74,color:#C2410C,stroke-width:2px,rx:10,ry:10
    style Res fill:#BFDBFE,stroke:#60A5FA,color:#1D4ED8,stroke-width:2px,rx:10,ry:10
    
    linkStyle 5 stroke:#EF4444,stroke-width:2px,color:#EF4444,stroke-dasharray: 5 5
```
</div>
